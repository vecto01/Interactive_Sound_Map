# Interactive Sound Map

## Описание

**Interactive Sound Map** — интерактивная карта звуковых точек, позволяющая изменять длительность звука и сохранять изменения в `localStorage`. Проект включает в себя адаптивный интерфейс, улучшенную доступность и анимации.

## Установка и запуск

Проект работает в браузере без установки дополнительных инструментов. Откройте файл `index.html` в браузере:

```bash
file:///D:/Vecto/projects/Interactive_Sound_Map/index.html
```

## Функциональность

### Основные возможности:
1. **Изменение длительности звука**: Введите значение длительности в секундах в поле ввода.
2. **Сохранение в localStorage**: Нажмите кнопку "Сохранить", чтобы сохранить изменения.
3. **Тестирование звука**: Нажмите кнопку "Test Sound", чтобы открыть модальное окно для тестирования звука.
4. **Переключение тем**: Используйте переключатель для переключения между светлой и тёмной темами.

### Доступность:
- Все интерактивные элементы поддерживают `:focus-visible` и `aria-*` атрибуты.
- Модальное окно закрывается по нажатию `Escape` или кнопке "Закрыть".
- Переключение фокуса по `Tab` работает корректно.

## Тестирование

### Доступность:
1. Откройте браузер и перейдите к проекту.
2. Нажмите кнопку "Test Sound", чтобы открыть модальное окно.
3. Проверьте, что:
   - Фокус переключается по `Tab`.
   - Кнопки и элементы модального окна имеют стили `:focus-visible`.
   - Модальное окно закрывается по `Escape`.

### Логика localStorage:
1. Введите значение длительности звука в поле ввода.
2. Нажмите кнопку "Сохранить".
3. Проверьте, что данные сохранены в `localStorage` и отображается соответствующее сообщение.
   - При переполнении `localStorage` отобразится сообщение об ошибке.

### Адаптивность:
1. Проверьте отображение на разных устройствах (десктоп, лэптоп, планшет, мобильное).
2. Убедитесь, что интерфейс адаптируется под ширину экрана.

### Проверка анимаций:
1. Запустите проект и проверьте:
   - Пульсация кнопки "Test Sound" при загрузке интерфейса.
   - Плавное открытие и закрытие модального окна.
   - Анимация вращения круга при загрузке.

## Инструкции по улучшениям

### Анимации:
- Загрузка интерфейса теперь включает анимацию пульсации кнопки при загрузке.
- Модальное окно открывается и закрывается плавно с использованием `transform` и `transition`.

### Контраст и читаемость:
- Добавлены стили `:focus-visible` для улучшения доступности.
- Текст и кнопки имеют достаточный контраст для всех устройств.
- Добавлены `media queries` для адаптивного отображения на разных разрешениях.

### Обратная связь:
- При наведении на кнопки появляется визуальная обратная связь (`hover`).
- Кнопки и элементы модального окна поддерживают `:focus-visible`.

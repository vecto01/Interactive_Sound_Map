# Interactive Sound Map

## Описание
Интерактивная карта с редактированием звуковых эффектов. Пользователи могут загружать звуки, редактировать их и сохранять в `localStorage`.

## Функциональность
- **Редактирование звуков**: Загрузка, воспроизведение и редактирование звуковых эффектов.
- **Адаптивный интерфейс**: Работает на всех устройствах (десктоп, лэптоп, мобильные).
- **Загрузка и анимации**: Плавные анимации загрузки и завершения процесса.
- **Доступность**: Поддержка ARIA-атрибутов и клавиатурной навигации.
- **Сохранение в localStorage**: Звуковые эффекты сохраняются между сессиями.

## Установка и запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/vecto01/Interactive_Sound_Map.git
   ```

2. Откройте файл `index.html` в браузере:
   ```bash
   file:///D:/Vecto/projects/Interactive_Sound_Map/index.html
   ```

## Тестирование
- **Мобильные устройства**: Проверьте адаптивность на эмуляторах или реальных устройствах.
- **Адаптивность**: Убедитесь, что интерфейс корректно масштабируется на разных разрешениях.
- **Анимации**: Проведите тестирование плавности анимаций загрузки и редактирования.

## Настройка
- **Темы**: Поддерживаются светлая и тёмная темы.
- **Звуки**: Добавьте звуковые файлы в папку `assets/sounds/` для редактирования.

# Interactive Sound Map

## Описание
Проект для взаимодействия с картой звуков. Позволяет сохранять настройки звука в `localStorage` и обрабатывать ошибки переполнения.

## Тестирование
### Доступность (a11y)
1. **Проверка `:focus-visible`**:
   - Откройте проект в браузере и используйте инструменты DevTools (Ctrl+Shift+I).
   - Переключитесь на вкладку "Accessibility" и проверьте, что все кнопки и элементы форм поддерживают `:focus-visible`.
   - Используйте скрипт `a11y-test.js` для автоматической проверки:
     ```javascript
     document.addEventListener('DOMContentLoaded', () => {
       console.log('Тест доступности :focus-visible запущен.');
       // Скрипт автоматически проверяет элементы
     });
     ```

2. **Проверка скролла модального окна**:
   - Откройте модальное окно и попробуйте прокрутить его. Убедитесь, что контент доступен для скролла.

### Анимации
1. **Проверка плавности анимаций**:
   - Используйте инструменты браузера для проверки плавности анимаций круга загрузки и модального окна.
   - Проверьте, что анимации не прерываются при скролле.

2. **Проверка темной темы**:
   - Включите темную тему в браузере и убедитесь, что текст и элементы интерфейса читаемы и адаптированы для неё.

### Логика `localStorage`
1. **Переполнение `localStorage`**:
   - Если `localStorage` переполнен, функция `saveSound` предложит пользователю очистить его или использовать `sessionStorage`.
   - Пример ошибки: `QuotaExceededError`.

## Как тестировать
1. Откройте проект в браузере.
2. Используйте инструменты DevTools для проверки доступности и анимаций.
3. Попробуйте сохранить звук несколько раз, чтобы проверить логику переполнения `localStorage`.

## Технические детали
- **Скрипты**:
  - `a11y-test.js` — проверка доступности.
  - `main.js` — основная логика проекта.
- **Стили**:
  - `styles/main.css` — основные стили.
  - `styles/loader.css` — стили загрузки.

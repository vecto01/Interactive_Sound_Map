# Interactive Sound Map

## Описание
Интерактивная карта с возможностью симуляции загрузки звука и тестирования функциональности.

## Установка и запуск
Проект работает в режиме `file:///` без необходимости установки.

1. Откройте файл `index.html` в браузере.

## Функциональность
- **Загрузка звука**: Показывается индикатор загрузки с плавной анимацией.
- **Тест загрузки**: Кнопка "Test Load Sound" для симуляции загрузки звука.
- **Ошибки загрузки**: Показывается сообщение об ошибке с высоким контрастом.
- **Темная/светлая темы**: Поддержка обоих режимов.

## Тестирование
1. **Адаптивность**: Проверьте работу на различных экранах (десктоп, планшет, мобильный).
2. **Доступность**: Используйте клавиатуру и инструменты доступности (например, VoiceOver на macOS).
3. **Производительность**: Проверьте отсутствие фреймерейтов и плавность анимаций в DevTools.

## Разработка
- **Стили**: Используются адаптивные медиа-запросы и относительные единицы (`rem`, `vw`).
- **Анимации**: Все анимации оптимизированы для плавности.
- **Доступность**: Добавлены ARIA-атрибуты и поддержка фокуса.

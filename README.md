# Interactive Sound Map

## Описание
Проект для интерактивной карты звуков. Позволяет пользователям сохранять и просматривать звуковые данные в браузере.

## Функциональность
- Загрузка и отображение звуковых данных.
- Сохранение звуков в `localStorage` и `sessionStorage`.
- Обработка переполнения `localStorage` и предложение пользователю использовать `sessionStorage` или очистить `localStorage`.
- Плавные анимации загрузки и завершения.
- Доступность (a11y) и проверка `:focus-visible`, ARIA-атрибуты.

## Установка
1. Откройте файл `index.html` в браузере.
2. Используйте кнопку "Test Sound" для проверки функциональности.

## Тестирование доступности
1. Откройте инструменты разработчика в браузере (F12).
2. Перейдите на вкладку "Accessibility" (Доступность).
3. Проверьте, что все элементы поддерживают `:focus-visible` и имеют ARIA-атрибуты.
4. Проверьте скролл и видимость элементов.

## Логика сохранения звуков
- Если `localStorage` переполнен, пользователю предлагается использовать `sessionStorage` или очистить `localStorage`.
- Логирование ошибок в консоль браузера.

## Скрипты
- `scripts/main.js`: Основная логика приложения.
- `a11y-test.js`: Проверка доступности.

## Стилизация
- Используются CSS-анимации для плавной загрузки и завершения.
- Поддерживается темная тема и адаптивность для всех устройств.

## Edge-кейсы
- Ограниченные ресурсы: проверка работы на слабых устройствах.
- Режим инкогнито: проверка доступа к `localStorage` и `sessionStorage`.
- Блокировка JavaScript: проверка отображения сообщений об ошибке.

## Документация
Для владельца:
- Все изменения и логика тестируются в браузере.
- Используйте инструменты DevTools для проверки доступности и анимаций.

# Interactive Sound Map

## Описание
Интерактивная карта звуковых эффектов с возможностью редактирования и сохранения пользовательских звуков.

## Функциональность
- Редактирование длины звука (от 1 до 10 секунд).
- Сохранение звуков в `localStorage` (обработка ошибок при переполнении).
- Отображение ошибок и сообщений об успешном сохранении.
- Доступность по клавиатуре: переключение фокуса по `Tab`, нажатие `Enter` для сохранения, `Escape` для закрытия модального окна.

## Тестирование
### На мобильных устройствах
- Проверьте адаптивность интерфейса на планшетах и смартфонах.
- Убедитесь, что звуки сохраняются и загружаются корректно.
- Проверьте доступность по клавиатуре (`Tab`, `Enter`, `Escape`).

### Производительность
- Проверьте плавность анимаций и отсутствие тормозов.
- Убедитесь, что загрузка страницы не занимает более 2 секунд.

## Условия использования
- Все звуки сохраняются в `localStorage` и доступны при повторном открытии страницы.
- При переполнении `localStorage` отображается уведомление об ошибке.
- Темный/светлый режим поддерживается через `localStorage`.

## Использование
1. Откройте страницу и нажмите кнопку "Test Sound", чтобы открыть модальное окно редактирования.
2. Введите длину звука (от 1 до 10 секунд).
3. Нажмите `Enter` или кнопку "Сохранить" для сохранения звука.
4. Нажмите `Escape`, чтобы закрыть модальное окно.
5. Убедитесь, что звук успешно сохранён или отображается сообщение об ошибке.

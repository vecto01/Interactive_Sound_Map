# Interactive Sound Map

## Описание
Интерактивная карта с редактированием звуковых эффектов и сохранением пользовательских настроек.

## Функциональность
- **Редактор звука**: редактируйте длительность звука и сохраняйте изменения в `localStorage`.
- **Адаптивный UI**: работает на всех устройствах (десктоп, планшет, мобильные).
- **Темная/светлая темы**: переключение тем через переключатель.
- **Доступность**: соблюдены WCAG стандарты для контраста и фокусировки.
- **Загрузка и анимации**: плавные анимации и корректная обработка загрузки.

## Как пользоваться
1. Нажмите на кнопку "Test Load Sound" для открытия редактора звука.
2. Введите длительность звука в секундах и нажмите "Сохранить".
3. Изменения сохраняются в `localStorage` и отображаются при повторном открытии.

## Технические детали
- **Тестирование**: адаптивность, доступность, производительность и юзабилити.
- **Структура**: разметка, стили и скрипты разделены по модулям.
- **Адаптивные медиа-запросы**: корректировка стилей для разных устройств.

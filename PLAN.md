# Interactive Sound Map

## Описание проекта
Проект для интерактивной карты звуков с возможностью сохранения звуковых данных в браузере. Поддерживает `localStorage` и `sessionStorage`, обработку переполнения и доступность (a11y).

## Завершение проекта
✅ **Анимации:**
- Загрузка и завершение загрузки с плавными анимациями.
- Плавное вращение и пульсация индикатора загрузки.
- Анимация появления текста
